Every tool and product on this site is listed as `Name (Creator)`, with the name linked to its own official page rather than a review or a listicle. The creator is left off when it is already part of the name (Microsoft Agent Framework, Pinecone), and for a solo or small project the actual person's name or handle is used instead of a company (Aider, Paul Gauthier).

Each Landscape page groups entries into three buckets: Commercial / Proprietary, Open Source / Provider-agnostic, and Legacy / Decommissioned. Open Source / Provider-agnostic requires both an open-source license and genuine support for more than one model provider: a tool built for a single provider's models is Commercial even if its code is open, and so is a self-hostable tool whose license is source-available rather than open source. A tool with a self-hostable open-source core and a separately hosted commercial version under the same brand is listed in both buckets, with a note connecting them. A product only moves to Legacy once its shutdown or rebrand has actually happened, not while it is announced but still supported. A mode that lives inside a larger product stays a sub-bullet of that product; once it becomes a genuinely separate product, it gets its own entry.

This page is a summary. The full method, kept current as the taxonomy changes, lives in this repository's [CONTRIBUTING.md](https://github.com/vishmatta/ai-agent-ecosystem/blob/main/CONTRIBUTING.md), though this site is not currently accepting outside contributions.
