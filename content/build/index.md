---
title: Build
---

Build covers how an agent gets assembled before it does anything: the [[build/agent-harnesses/index|harness]] or [[build/agent-frameworks/index|framework]] it runs in, the [[build/models/index|model or models]] behind it, the [[build/orchestration-patterns/index|orchestration pattern]] that coordinates multiple steps or agents, and the [[build/agent-behavior/index|behavior policies and guardrails]] that constrain what it is allowed to do. These choices are made once, at construction time, but they set the ceiling for what Connect and Run can later do with the agent.
