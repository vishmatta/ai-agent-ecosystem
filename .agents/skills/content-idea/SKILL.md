# Content idea to issue

This skill is a shortcut. The procedure lives in the repository, so every tool
follows the same one.

1. From the repository root, read `docs/agents/intake.md` and follow it
   exactly.
2. The idea is whatever the user wrote with this request, or the body of the
   `idea` issue they named. If there's neither, ask for the idea in one
   sentence.
3. Stop where intake stops. Report what you created and why: the issue and its
   labels, or the research note, or the issue you commented on — intake routes
   to all three. Don't start the work.

If this file and `docs/agents/intake.md` ever disagree, `docs/agents/intake.md`
wins.
